# REM-P1-065 实施合同

## 已确认目标

- 提供流程绑定创建、编辑、启用、停用、删除和流程定义版本选择。
- 绑定变更只影响新启动实例，不追溯或迁移已有运行实例。
- 全部 mutation 受 `workflow:configure` 保护并写审计。
- 保留现有 tenant/businessType 唯一绑定与模板业务类型校验。
- 真实业务启动必须消费当前启用的指定定义版本。

## 已批准的高风险语义

用户于 2026-07-21 明确批准：

1. 绑定采用软删除，需要数据库迁移增加软删除字段并将唯一约束调整为仅活动记录唯一。
2. 停用或删除后，新业务启动稳定拒绝并明确提示“未配置启用的流程绑定”，不回退旧 `sys_config` 兼容键。
3. 已运行实例继续按原定义执行；不级联终止或迁移。
4. 重新启用前重新校验流程定义存在、未挂起且模板业务类型匹配。
5. 删除前若存在运行实例不阻断，因为实例已固化定义；但删除只移除未来启动选择，不删除 Flowable 定义、模板或实例。
6. 兼容键在绑定/启用时同步当前定义；停用/删除时清空，禁止形成隐式第二绑定来源。

兼容边界：从未存在统一 binding 记录的历史业务类型仍可读取旧键完成迁移兼容；一旦存在活动、停用或已删除的统一 binding 记录，就以统一 binding 为唯一来源，停用/删除不会回退旧键。

## 非目标

- 不终止、迁移或删除运行/历史流程实例。
- 不删除流程定义或模板实例。
- 不修改日报、Wiki、变更文档审批状态机。
- 不直接 SQL 写入，不操作正式 binding，不执行 restore。

## 回滚

回滚事件提交和迁移；运行时只创建唯一 runId 定义与绑定，按产品 API 逆序删除。不得覆盖或删除 daily/wiki 正式绑定作为测试夹具。
