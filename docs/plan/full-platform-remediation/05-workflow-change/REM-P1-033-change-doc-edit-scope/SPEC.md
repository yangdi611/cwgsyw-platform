# REM-P1-033 实施合同

## 已确认的资源范围

同租户内，所有变更文档入口以申请人当前主组为范围依据：

| 调用者 | 可访问文档 |
|---|---|
| 普通成员 | 仅本人申请的文档 |
| 组长 | 本组成员申请的文档 |
| `tenant` / `platform` scope | 全租户文档 |

范围适用于列表、详情、快照、导出、邮件模板、AI 生成、更新、提交、补交方案、删除、审批与 CI 关联的读写。越权对象返回 `404 RESOURCE_NOT_FOUND`，不泄露同租户文档是否存在。列表必须在数据库分页前施加范围过滤，保证 `total`、页数和记录一致。
