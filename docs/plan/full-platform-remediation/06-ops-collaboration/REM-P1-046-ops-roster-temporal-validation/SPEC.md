# REM-P1-046 实施合同

## 目标

排班创建和更新拒绝 `endAt <= startAt`，返回现有统一输入错误语义，并保持合法跨日时间可用。

## 验收标准

- 同日反向时间和相等时间在 create/update 均返回 400，数据库无写入。
- 合法同日时间和合法跨日时间保存、读取一致。
- 当前 `OPS-016` 完整 CRUD、主备人员、电话、反向时间和精确清理通过。
- 不改变权限、租户、冲突检测、清理端点、审计或数据库结构。

## 非目标

- 不改变跨日排班语义。
- 不增加普通业务删除 API，不修改前端页面合同。

## 回滚

移除 Service 时间校验和对应测试；无迁移、配置或数据回填。
