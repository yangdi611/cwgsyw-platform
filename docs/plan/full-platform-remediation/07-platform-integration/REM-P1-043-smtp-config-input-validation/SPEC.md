# REM-P1-043 实施合同

## 目标

SMTP 配置的非法 host、port 和发件地址必须在写入前返回 HTTP/body 400，原配置保持不变。

## 验收标准

- host 接受空值、单标签容器名、DNS/IPv4 和方括号 IPv6；拒绝空白、协议、路径、连续点和超过 253 字符。
- port 仅接受 `1..65535`。
- from 为空或合法邮件地址；拒绝非法邮件格式。
- 合法 Mailpit 配置可保存、读回并真实发送，随后恢复完整原配置。
- 非法请求不产生任何部分写入；权限拒绝、密码掩码和字段部分更新合同不变。

## 非目标

- 不改变 SMTP 发送时机、通知候选人、认证、TLS 或密码存储语义。
- 不修改通知、Prometheus、水印或 AI provider 配置。
- 不连接真实 SMTP，不记录任何秘密。

## 回滚

移除 DTO 约束和 Controller `@Valid` 即可；无迁移、数据回填或配置默认值变化。
