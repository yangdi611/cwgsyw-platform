# REM-P1-066 实施合同

## 目标

- 导入 preview 或 execute 请求 pending 时关闭对话框，旧回调不得改变关闭后或后续新打开的 UI 状态。
- 每次重新打开都从上传步骤、空文件、默认格式/冲突策略/编码开始。
- 保留现有 CSV/JSON preview、execute、progress、结果和错误反馈 API 合同。

## 非目标

- 不取消已经发送到后端的导入请求，不改变后端导入事务语义。
- 不修改 CMDB 数据模型、导入格式、失败行或清理端点。
- 不使用真实产品导入写入作为竞态夹具。

## 验收

| ID | 合同 |
|---|---|
| AC-001 | pending preview 关闭后完成，重新打开仍为干净上传步骤。 |
| AC-002 | pending execute 关闭后完成，重新打开不显示旧结果且文件为空。 |
| AC-003 | 正常未关闭 preview/execute 行为保持不变，typecheck/lint/build 通过。 |
| AC-004 | 真实容器浏览器复验无产品写入、无未解释 5xx。 |

## 回滚

回滚事件提交即可；无迁移、配置或产品测试数据需要恢复。
