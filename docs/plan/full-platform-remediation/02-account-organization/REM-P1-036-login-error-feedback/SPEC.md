# REM-P1-036 实施合同

## 根因

`frontend/src/lib/api.ts` 将所有 `401` 都交给 `redirectToLogin()`。`POST /auth/login` 的错误凭据也因此重载 `/login`，卸载登录页面的局部错误状态。

## 验收

| AC | 合同 |
|---|---|
| AC-001 | 错误密码与不存在用户名均保持 `/login`，显示统一“用户名或密码错误”，无 token。 |
| AC-002 | 空用户名/密码保持浏览器原生必填校验，不发登录请求。 |
| AC-003 | 其他受保护 API 的会话无效 `401` 仍清理认证状态并跳转登录。 |
| AC-004 | 后端错误码、失败登录审计、密码策略和成功登录路径不变。 |
| AC-005 | 当前事件分支构建的前端容器上完成真实浏览器复验。 |

## 回滚

回滚本事件提交即可恢复原拦截器；不需要数据、Redis 或会话清理。
