# REM-P1-072 规格

## 范围

- 修复 CSV 导入执行后失败行无法下载的问题。
- 失败结果必须绑定 `tenantId`，独立保存并设置有界 TTL。
- 下载 CSV 必须包含失败原始字段、行号和失败原因，并正确处理逗号、引号、换行和公式前缀。

## 非目标

- 不改变 CSV 预览校验、实例导入业务规则或导入权限。
- 不延长预览数据生命周期，不直接操作 Redis、数据库或对象存储。
- 不提供跨租户读取、永久失败结果保存或新的批量清理入口。

## 验收标准

- AC-001：执行成功或失败后，失败结果在 TTL 内可通过现有下载路由取得；预览键仍按原合同删除。
- AC-002：下载仅允许结果所属租户；缺失、错误租户和过期结果稳定拒绝且无业务写入。
- AC-003：CSV 包含原始失败行、行号和失败原因；空失败列表仍返回有效 UTF-8 CSV。
- AC-004：逗号、引号、换行和 `=+-@` 开头值按 CSV/公式注入安全规则输出。
- AC-005：Java 21 定向测试、当前分支 backend 构建替换、真实 API/Playwright 和 CMDB 测试数据精确清理通过。
