- 用例：`WIKI-016`
- 根因：WikiPageVersion 快照写入/读取与 revert→savePage 映射未保证正文、标题和版本元数据完整。
- 原始证据：`defects.md` 对应章节和 `test-results/FQA_20260712_0329_lintfix/`；保持只读。

范围：
- 固定版本快照 schema
- 修复回退事务与新版本生成
- 保证正文、标题、附件引用和审计一致
- 对空/旧格式快照提供受控失败

- 不删除历史版本
