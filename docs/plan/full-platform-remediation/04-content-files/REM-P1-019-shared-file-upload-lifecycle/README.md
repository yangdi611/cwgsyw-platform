## 问题与影响

上传接受零字节、同目录同名无冲突合同，成功后列表不呈现，且没有进度、取消或中断补偿。

用户可能重复上传、看不到已上传文件，或在取消/网络中断后留下存储半成品。

## 追溯与边界

- 缺陷：`BUG-FQA-065`、`BUG-FQA-066`、`BUG-FQA-068`、`BUG-FQA-100`
- 用例：`FILE-005`、`FILE-008`、`FILE-013`、`FILE-014`
- 根因：前端 mutation、文件列表 query key、后端存储与数据库写入没有统一上传状态机和幂等/补偿协议。
- 原始证据：`defects.md` 对应章节和 `test-results/FQA_20260712_0329_lintfix/`；保持只读。

范围：
- 零字节/名称/大小/MIME 校验
- 同目录规范名唯一与并发冲突
- 上传进度与取消状态
- 存储成功/数据库失败及中断补偿
- 成功后准确刷新当前目录

非目标：
- 不实现分片大文件上传
- 不改变现有 ACL 模型
- 不清理无法证明归属的历史对象
