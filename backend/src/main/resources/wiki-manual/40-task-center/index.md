# 任务中心与统一任务

统一任务是平台处理日报、周报、季报、巡检、检查、资料收集和临时事项的唯一机制。创建者先定义模板和计划，系统据此生成任务；执行人填写表单、上传附件并提交；需要审批的任务再进入审批闭环；正式提交的数据可以用于统计。

## 核心概念

| 对象 | 用途 | 谁通常使用 |
|---|---|---|
| 任务模板 | 定义任务说明、表单字段、附件要求、校验与统计语义 | 模板管理员 |
| 模板版本 | 每次发布后的不可变快照，历史任务始终引用生成时的版本 | 模板管理员、审计人员 |
| 任务计划 | 定义一次性或周期时间、执行对象、CI 范围、提醒和审批方案 | 计划管理员 |
| 一次性任务 | 立即下发的临时任务，也必须选择已发布模板 | 任务创建者 |
| 任务实例 | 某人在某日期实际要完成的一项工作 | 执行人 |
| 提交版本 | 一次正式填报的表单和附件快照；退回后重新提交会产生新版本 | 执行人、审批人 |
| 审批轮次 | 一次提交后的审批过程；通过、退回或终止均保留记录 | 审批人 |
| 指标与看板 | 对已授权、有效任务事实的统计和展示 | 统计管理员、查看者 |

## 推荐使用流程

```text
明确业务要求
  -> 创建并发布任务模板
  -> 创建任务计划，或直接新建一次性任务
  -> 激活计划/下发任务
  -> 执行人填写、保存草稿、上传附件、提交
  -> 可选审批：通过，或退回后修改重提
  -> 在统计中心查询、看板、导出或触发后续自动化
```

## 选择正确入口

| 要做的事 | 入口 |
|---|---|
| 处理自己要执行或要审批的事项 | 左侧导航 → 我的工作 |
| 看某天有哪些任务、排班或节假日 | 左侧导航 → 运维日历 |
| 临时给某位同事下发一项任务 | 运维日历 → 新建任务 |
| 创建日报、巡检、周报等可复用表单 | 任务中心 → 任务模板 |
| 按日期自动生成任务 | 任务中心 → 任务计划 |
| 搜索、筛选和跟踪任务 | 任务中心 → 任务列表 |
| 分析数字、选项、文字或附件 | 任务中心 → 任务统计 |
| 建立权威指标、目标和自动化 | 任务中心 → 指标与目标 / 任务自动化 |

## 内置模板和常见场景

系统提供“简易任务”“工作日报”“基础巡检”等已发布模板。内置模板的内容保持只读，以保证系统标准场景稳定；具备模板删除权限的用户可删除未被任何任务或任务计划引用的内置模板。需要改动字段、审批或统计口径时，请复制或新建租户自定义模板，再由计划引用新模板。

| 场景 | 建议做法 |
|---|---|
| 工作日报 | 使用“工作日报”模板创建工作日计划；执行人在“我的工作”完成当天填报 |
| 每日巡检 | 以巡检字段、CI 范围和附件要求创建模板，再建立每日或工作日计划 |
| 周报/季报 | 使用独立模板和独立统计维度；如需引用日报汇总，请使用“引用汇总”字段或指标绑定 |
| 临时检查或资料收集 | 使用“简易任务”或适用的已发布模板，从日历快速创建一次性任务 |
| 有整改闭环的事项 | 在计划中选择审批方案，并可在“任务自动化”中配置通过、完成或阈值后的后续动作 |

## 状态说明

任务执行状态和审批状态是两套状态，不能互相替代。

| 类别 | 常见状态 | 含义 |
|---|---|---|
| 执行 | 待执行、进行中、待提交、已完成、已逾期、已退回 | 描述工作是否被执行和提交 |
| 审批 | 无需审批、审批中、已通过、已退回、已拒绝、已终止 | 描述提交版本的审批结果 |

例如，任务“已提交审批”并不等于“已完成”；需要审批时，只有审批通过后才会成为正式有效结果。任务被退回后，执行人应在原任务中修改并重新提交，不能另建一份任务替代原记录。

## 使用边界

- 模板发布后不能直接修改。需要变更时创建下一草稿版本，发布后只影响新生成的任务。
- 任务详情中的可操作按钮由系统按当前身份、任务状态和数据范围决定；看不到按钮通常表示没有权限或当前状态不允许操作。
- 不要在文本字段中记录密码、密钥等敏感凭据。此类信息应使用设备密码库或经授权的文件管理能力。
- 统计、导出和附件下载都遵循任务权限；看板不会扩大你对原始任务的访问范围。
