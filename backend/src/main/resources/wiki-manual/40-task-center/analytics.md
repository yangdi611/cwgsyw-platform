# 统计、指标与自动化

本章面向统计管理员、管理者和分析人员。所有统计均基于统一任务的正式提交数据，并自动遵循原任务、字段、附件和组织权限。

## 一、先理解统计范围

不同报表不必共用相同字段或维度。日报、周报、季报和巡检应分别使用自己的任务模板；统计时先选择一个模板和字段，再配置时间、聚合和维度。这样可以避免把名称相似但口径不同的数据强行相加。

| 数据类别 | 合适的汇总方式 | 常见展示 |
|---|---|---|
| 数字、金额、百分比、评分、时长 | 合计、平均、最小、最大、计数、去重计数 | KPI、趋势、分组表 |
| 单选、多选、标签、人员、组、CI、日期 | 计数、去重计数、按值分组 | 分类图、排行榜、透视表 |
| 多行文本、表格、重复区块 | 明细、关键词筛选、结构化明细 | 明细列表、下钻 |
| 文件、图片 | 附件数量、文件清单、图片墙 | 数量卡片、附件列表、图片墙 |

敏感字段不会用于统计或导出。统计结果为空不一定代表没有数据，也可能是你没有原任务权限、所选时间内没有通过的提交，或字段没有启用统计语义。

## 二、运行一次统计查询

路径：**任务中心 → 任务统计**。

1. 选择任务模板。系统只列出该模板允许统计的字段。
2. 选择统计字段。字段类型决定可选的聚合方式；例如“巡检次数”可选合计或平均，“风险等级”可按分类计数。
3. 设置聚合方式和输出类型。
4. 设置开始/结束日期、时间粒度和可选维度；可再用文本搜索缩小范围。
5. 点击“运行统计”。
6. 在结果中查看 KPI、趋势、分组、文字/附件明细或图片展示，并按需要下钻到源任务。

统计以业务日期为主，不应把任务创建时间误当作发生时间。跨周期分析时，先明确统计的时间范围和粒度，再比较不同模板的结果。

### 看板与导出

查询结果可保存为看板，供授权用户重复访问；看板仍按查看者的任务权限过滤内容。可按页面提供的 CSV 或 Excel 操作导出当前已授权结果。导出前应确认：字段不是敏感字段、时间范围正确、分组维度没有混入不同口径模板。

## 三、维护指标

路径：**任务中心 → 指标与目标**。

指标用于建立跨报表可复用的业务口径，例如“每日巡检次数”“异常数”“工时完成率”。

### 创建指标

1. 新建指标，填写名称、编码、值类型和单位。
2. 选择权威来源策略。对于同一指标，明确哪些值是正式事实、系统汇总或人工上报。
3. 将已发布模板中的统计字段绑定到指标，必要时填写单位换算系数。
4. 使用“期间预览”选择日期范围，核对系统汇总、人工上报、差异和来源任务数量。

比率指标需要分别绑定分子和分母。不要把日报自动汇总值和周报人工总数同时作为同一事实来源，否则会造成重复累计。应通过来源角色区分 `fact`、系统汇总和人工上报，并以权威来源策略决定正式口径。

### 设置指标目标

为指标设置目标值、预警/严重阈值、比较方式、周期和生效区间。目标可作用于租户、组、用户或模板范围。不同时间段或不同组织可以有不同目标，历史结果按当时的组织和任务快照解释。

## 四、配置任务自动化

路径：**任务中心 → 任务自动化**。自动化使用受控条件和动作，不支持脚本、SQL 或任意 URL。

### 可用触发器和动作

| 触发器 | 可选动作 | 示例 |
|---|---|---|
| 审批通过 | 创建后续任务、发送通知 | 巡检报告通过后创建整改任务 |
| 任务完成 | 创建后续任务、发送通知 | 月度检查完成后提醒负责人复核 |
| 指标阈值 | 创建后续任务、发送通知 | 异常次数超过阈值时通知值班负责人 |

### 创建和启用规则

1. 填写名称和说明。
2. 选择触发器；指标阈值触发器还要选择指标。
3. 可选配置条件字段、比较运算符和条件值。
4. 选择动作。创建任务时选择已发布模板、执行人和截止小时数；发送通知时选择接收人和标题。
5. 保存为草稿规则，填写来源任务 ID 后使用“预演”检查是否会命中及解析出的动作。
6. 预演无误后激活规则。规则列表可暂停、编辑草稿规则或删除不再需要的规则。

执行记录会显示成功、失败或死亡状态，以及创建出的任务或错误原因。对失败记录可按权限提交重试；修改规则前建议先暂停，避免在错误条件下继续触发。

## 五、统计与审计原则

- 统计下钻必须回到原任务和提交版本，因此任何 KPI 都可追溯到模板、字段、提交、审批和来源任务。
- 人员调组后，历史任务按执行时的组织快照统计；新任务按新组织统计。
- 被退回、拒绝或终止的提交不会替代已通过的正式事实；重提通过后，系统按当前有效提交处理。
- 看板订阅、导出和自动化都不会绕过任务权限。需要扩大可见范围时，应调整角色、组范围或任务授权，而不是共享导出文件。

## 排查清单

**统计字段不可选：** 检查模板版本中该字段是否启用统计语义，是否被标记为敏感，以及当前用户是否有统计权限。

**结果为零或为空：** 检查时间范围、业务日期、模板、提交是否已通过、数据权限和筛选条件；不要直接修改原始提交来“补数据”。

**数值不一致：** 核对单位换算、聚合方式、权威来源、自动汇总与人工上报是否被正确区分，再查看期间预览的来源任务数量。

**自动化没有执行：** 检查规则是否激活、触发事件是否满足条件、执行记录是否失败，以及所选模板、执行人和通知接收人是否仍有效。
