# 任务执行、审批与运维日历

本章面向执行人、审批人和任务创建者，说明如何处理实际任务、查看退回原因和按日期跟踪工作。

## 一、我的工作

路径：**左侧导航 → 我的工作**。这是处理个人任务和审批的唯一入口，页面提供五个集合：

| 集合 | 何时查看 | 可以做什么 |
|---|---|---|
| 待执行 | 有人指派给你，或周期计划为你生成了任务 | 打开任务、开始、填报、保存草稿、上传附件、提交 |
| 待审批 | 你是当前审批节点的审批人 | 查看提交、附件、历史和差异后处理审批 |
| 我发起的 | 你创建了一次性任务或计划产生的相关任务 | 跟踪执行、提交和审批进度 |
| 抄送我的 | 任务或审批结果抄送给你 | 只读查看相关内容 |
| 已完成 | 已完成或已结束的事项 | 查询历史、打开详情和提交版本 |

可按关键字、模板、状态、优先级、逾期、组和日期筛选。列表中“需要处理”表示当前需要你执行或审批；点击一行进入任务详情。不要把“我发起的”当作代替执行人的入口，实际填报仍由任务详情的动作权限控制。

## 二、执行任务与提交

### 打开和开始

从“待执行”、任务列表或运维日历打开任务。详情页显示任务说明、模板、执行状态、审批状态、截止时间和当前允许的操作。若有“开始任务”按钮，先点击开始；没有该按钮时，系统可能已自动开始或该状态不要求手动开始。

### 填写表单

1. 按字段说明完成填写；必填字段会在提交前校验。
2. 在文件或图片字段处上传所需附件。附件在草稿阶段可删除或替换；提交后会作为提交版本快照保留。
3. 遇到“自定义表格”时，只填写已配置的列。可按实际工作量新增、复制或删除行；序号列由系统自动生成。表格内附件始终绑定到当前行和当前列。
4. CI 范围字段只显示你有权查看、且被模板范围限定的具体 CI。找不到目标 CI 时，不要用文字字段替代，请联系模板或 CMDB 管理员检查权限和范围。
5. 条件字段可能随前序答案显示或隐藏；公式和引用汇总字段由系统计算，不要手工覆盖计算结果。

### 草稿和自动保存

填写后系统会自动保存草稿；也可点击“保存草稿”。草稿不是正式提交，审批人和统计不会把草稿作为有效结果。若系统提示版本冲突，先刷新查看最新内容，再决定是否重新填写，避免覆盖其他协作人的修改。

### 提交

点击“提交任务”。系统会校验必填、格式、附件数量、表格行和条件规则：

- 没有审批方案：提交成功后任务完成，数据成为正式结果。
- 有审批方案：提交成功后状态变为审批中，等待审批人处理。

提交前请确认日期、数字单位、关联 CI 和附件均准确。需要修改正式提交时，必须等待退回或按管理规则处理，不能通过新建相似任务替代历史记录。

## 三、审批、退回与重提

审批人从“我的工作 → 待审批”打开事项。审批抽屉或任务详情会展示任务摘要、表单、附件、提交版本、此前审批轮次和与上一提交的差异。

### 审批人操作

- **通过**：确认本次提交符合要求。通过后任务完成，相关数据成为正式统计事实。
- **退回修改**：必须填写退回理由。可针对具体字段或附件留下意见；执行人会在任务详情的退回提示、字段/附件意见和审批历史中看到原因。
- **终止/拒绝**：用于不应继续执行的提交。必须填写理由，并按权限使用。

审批意见应说明可执行的修改要求，例如“巡检次数缺少第二机房数据，请补充附件截图”，避免只写“不同意”。

### 执行人收到退回后

1. 在“待执行”或通知中打开原任务。
2. 阅读页面顶部退回理由，并查看对应字段和附件旁的意见。
3. 修改草稿、补充附件或更正表单。
4. 点击“重新提交”。

重新提交会形成新的提交版本和新的审批轮次；旧提交保留为历史，系统显示字段和附件差异。不要删除原任务或通过创建新任务来规避退回。

## 四、任务历史与审计

任务详情包含提交历史和审批历史：

- 选择任一提交版本可查看当时的表单和附件快照。
- 差异视图展示相对上一版本新增、修改或移除的字段和附件。
- 审批轮次保留审批节点、处理人、动作、时间和意见。
- 任务时间线保留开始、草稿、提交、审批、提醒等关键事件。

这些记录用于审计和问题复盘。已提交附件的权限仍遵循该任务及字段的访问范围。

## 五、运维日历

路径：**左侧导航 → 运维日历**。日历只负责按日期展示和快速进入事项，不维护另一套任务数据。

### 视图与导航

- 使用“月 / 周 / 列表”在同一页面切换视图；筛选条件和日期上下文会保持。
- 使用“今天”和左右箭头快速定位日期范围。
- 点击某日可查看该日事项；点击具体任务、排班或节假日可进入相应详情或工作入口。
- 月视图每个日期最多展示部分事项，点击“更多”或日期可查看完整列表。

### 筛选

日历支持“我的 / 本组 / 全部”范围，以及任务模板、负责人、所属组、显示内容和执行状态筛选。可见的范围和人员/组选择器取决于你的数据权限。

“显示内容”可选择：

- **任务**：统一任务实例，包括一次性任务、日报、巡检和周期任务。
- **排班**：值班排班信息。
- **节假日**：节假日历信息，供节假日前后计划和日常判断使用。

有创建权限时点击“新建任务”可快速下发一次性任务，详见 [[任务模板与计划]]。日历设置权限用户可从“设置”进入排班管理和节假日历维护；普通执行人不需要也不应修改这些基础日历数据。

## 六、任务列表与通知

**任务中心 → 任务列表**适合管理员或负责人跨任务检索：可按我的、本组或全部范围、模板、计划、执行/审批状态、优先级、逾期、负责人、组和业务日期筛选。

任务临期、逾期、提交、审批通过、退回和终止等事件会进入通知中心。通知只提供提醒和跳转，正式处理仍应在任务详情或“我的工作”中完成。

## 常见问题

**为什么看不到任务？** 先检查“我的工作”的集合和筛选；再确认自己是否是执行人、审批人或抄送人。仍找不到时联系计划管理员检查分派规则和生效日期。

**为什么不能提交？** 查看表单底部的校验提示，检查必填字段、附件、条件字段和截止时间。若按钮不存在，说明当前任务不允许你编辑或已进入审批/完成状态。

**为什么看不到附件或字段？** 可能是模板条件、敏感字段策略或任务数据权限所致，不要请求通过统计导出或其他账号绕过限制。

**为什么日历里有任务但我的工作没有？** 日历可以展示你有权查看的组内事项；“我的工作”只聚合需要你处理、你发起、抄送或已完成的事项。
