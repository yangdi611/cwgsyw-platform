# 平台简介与快速上手

欢迎使用 IT 基础设施运维运营管理平台。本手册介绍平台各功能模块的用途与使用方法，帮助你快速上手。

## 平台能做什么

本平台帮助运维团队集中管理 IT 基础设施与日常运维工作，主要功能包括：

- **[[CMDB 配置管理]]** — 管理服务器、应用等配置项及其关联关系，是平台的数据基础
- **[[设备密码库]]** — 集中、加密保管设备登录凭据
- **[[任务中心与统一任务]]** — 用模板创建一次性或周期性任务，统一完成填报、附件、审批、提醒和统计
- **[[任务执行、审批与运维日历|我的工作与运维日历]]** — 查看待执行和待审批事项，并按日期跟踪任务、排班与节假日
- **[[变更文档]]** — 规范化的变更申请、审批与归档
- **[[共享文件库]]** — 团队文件的分类存储与共享
- **[[Wiki 知识库使用说明|Wiki 知识库]]** — 团队知识沉淀（本手册即在此）
- **[[系统管理]]** — 用户、权限、系统配置与数据备份（管理员）

## 如何登录

1. 打开平台地址，输入用户名和密码
2. 登录后进入[[工作台]]首页
3. 左侧导航栏列出你有权限访问的所有模块

首次登录后，先确认右上角显示的是自己的姓名，再从左侧菜单进入工作模块。系统不会把无权限菜单显示出来；直接访问链接后被带回工作台，通常表示角色尚未获得该页面权限。

## 导航说明

左侧导航栏按模块分组。你能看到哪些菜单，取决于管理员分配给你的角色权限。如果某个功能你看不到，说明你当前没有对应权限，可联系管理员开通。

页面右上角是通知铃铛（有未读消息时显示红点）和个人菜单（退出登录在此）。任务临近截止、退回修改、审批待处理等消息会在通知中心集中展示。

## 从哪里开始

| 你的目标 | 建议入口 |
|---|---|
| 处理今天要做的任务或审批 | [[任务执行、审批与运维日历|我的工作]] |
| 查看任务在什么日期执行 | [[任务执行、审批与运维日历|运维日历]] |
| 创建可复用的表单任务 | [[任务模板与计划]] |
| 配置日报、巡检、周报等周期工作 | [[任务模板与计划]] |
| 汇总巡检次数、工时或附件数量 | [[统计、指标与自动化]] |

日报、周报、季报和巡检不再拥有独立模块。它们都是任务模板：进入“我的工作”完成填报，进入“任务中心”维护模板和计划。

## 按角色开始工作

### 执行人

1. 登录后先打开“我的工作 → 待执行”。
2. 确认截止时间、优先级和模板说明；逾期事项会有状态标识。
3. 打开任务填写表单、上传附件；可先保存草稿，确认无误再提交。
4. 有审批的任务提交后进入审批中；被退回时在原任务查看原因、修改并重新提交。

### 审批人

1. 打开“我的工作 → 待审批”。
2. 查看提交表单、附件、历史版本和此前意见。
3. 符合要求时通过；需要修改时退回并填写具体原因；不应继续的事项按权限终止。

### 任务创建者或组长

1. 临时事项从“运维日历 → 新建任务”下发。
2. 周期工作从“任务中心 → 任务模板 / 任务计划”配置、预览后激活。
3. 在“任务列表”“我发起的”和“运维日历”跟踪进度。
4. 需要汇总时使用“任务统计”，不要手工复制不同模板的数据相加。

### 管理员

管理员先维护用户、用户组、角色和权限，再按需开放业务模块。涉及邮件、监控、备份和恢复的配置应在维护窗口内操作，并在操作后检查通知、日志或健康状态。

## 角色与权限

平台用「角色」控制每个人能做什么。常见角色：

| 角色 | 能做什么 |
|------|---------|
| 超级管理员 | 全平台所有功能 |
| 管理员 | 本租户所有功能 |
| 组长 | 本组管理 + 审批 |
| 组员 | 基本读写 |
| 只读 | 仅查看 |

具体权限以管理员实际分配为准。详见 [[用户与权限管理]]。

## 关于本手册

本手册由系统统一维护，随平台版本更新自动同步，普通用户为只读浏览。每个模块的详细用法见对应章节。

阅读时优先按左侧目录逐页进入。文中的 `[[页面名称]]` 是可点击内部链接；页面没有显示某个按钮时，先检查权限说明，再联系管理员处理授权，而不是尝试使用其他人的账号。
