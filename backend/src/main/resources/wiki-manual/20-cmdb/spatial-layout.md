# 机房空间布局

机房空间布局用于回答“设备在机房的什么位置”。它以统一的二维逻辑图展示机房外轮廓、机柜列、机柜位、通道、区域和设施，并把机柜或设施链接到已有的 CMDB 配置项。

空间布局不是 CAD 图纸，也不替代机柜 U 位图或关系拓扑。原始平面图可以作为编辑时的参考，但机柜位置和 CI 绑定以已发布的空间布局为准。

## 先了解三个视图的区别

| 需要解决的问题 | 使用入口 | 结果 |
|------|------|------|
| 设备在机房哪里 | **CMDB → 空间布局** | 机房、机柜列、机柜位和设施的二维位置 |
| 某个机柜内安装了什么 | 机柜详情 → 机柜视图 | U 位、设备占用和容量 |
| CI 之间如何依赖或连接 | CI 详情 → 拓扑 | 关系、上下游和影响范围 |
| 同一模型按属性如何分布 | CMDB → 拓扑 | 2D 分组网格 |

空间布局只维护位置和图形。CI 名称、状态、告警、机柜容量和设备 U 位仍由 CMDB、告警中心和机柜视图维护，不应在布局中手工重复录入。

## 查看已发布布局

1. 进入 **CMDB → 空间布局**。
2. 在列表中选择已配置且已发布的机房。
3. 画布会自动适配机房范围。使用右上角的放大、缩小和适配按钮浏览图面；鼠标拖动或触控拖动可平移画布。
4. 点击机柜位或设施，右侧会显示位置、关联 CI、状态、活动告警和机柜容量摘要。
5. 在右侧详情中可进入“机柜视图”“CI 详情”或“关系拓扑”。这些入口打开的是已有 CMDB 功能，数据口径与原页面保持一致。

### 使用图层

查看器一次只显示一种主图层，避免不同颜色含义叠加：

- **布局**：显示机房结构、机柜位、通道、区域和设施。
- **状态**：用颜色表示绑定 CI 的运行状态。
- **告警**：突出存在活动告警的机柜或设施；数字表示告警数量。
- **容量**：按机柜已用 U 位比例显示容量状态。
- **质量**：标出 CI 缺失、无权读取或绑定数据异常的位置。

运行图层来自当前 CMDB 和告警数据，刷新后颜色或摘要可能变化；它不会修改已发布布局。

### 搜索并定位

1. 在页面顶部输入机柜名称、设备名称、资产信息或管理 IP，按 Enter。
2. 结果会显示“机房 > 机柜 > 目标 CI”的位置路径。
3. 选择当前机房内的结果，系统会自动选中、高亮并缩放到对应机柜位。
4. 选择其他机房的结果，系统会自动进入目标机房布局。

若没有结果，先确认目标 CI 未归档、已与机柜建立正式关联，并且所在机房已经发布空间布局。

## 创建和编辑布局

创建、编辑、上传参考图和保存草稿需要空间布局编辑权限；发布、恢复和归档需要发布权限。

1. 在空间布局列表中选择尚未配置的机房并新建布局。
2. 进入机房后选择“编辑”。编辑器只适合桌面宽屏使用。
3. 先放置一个机房外轮廓，再添加墙、门、通道、区域、设施、文字和机柜位。
4. 使用“机柜列生成”填写列代码与数量，批量生成稳定编号的机柜位，例如 `F-01` 到 `F-09`。
5. 选中机柜位，在右侧从候选机柜中绑定 CI。候选只包含当前机房已建立正式包含关系的机柜；被其他位置占用的候选不可重复绑定。
6. 选中设施时可按需要绑定空调、UPS、配电柜等其他 CI，也可以只作为未绑定的空间标记。
7. 如需对照原始机房图，上传 PNG、JPEG 或 WebP 参考图。参考图仅用于编辑对照，默认不会在已发布视图显示。
8. 点击“保存”保存草稿；可使用撤销、重做、缩放和适配画布调整布局。

### 在环境之间迁移图纸

测试环境和生产环境的 CI 标识不同，因此空间布局编辑器提供的是“图纸迁移”，而不是整张布局和业务数据的复制。

1. 在已经完成绘制的测试环境进入布局编辑器，先校验图纸内容。
2. 点击顶部的“导出图纸”，浏览器会下载一个 JSON 图纸文件。
3. 在生产环境为目标机房新建或打开布局草稿，点击“导入图纸”并选择该文件。
4. 系统校验文件后会提示确认。确认导入会替换当前草稿中的全部图纸元素；如选错文件，可立即使用“撤销”。
5. 检查机房外轮廓、机柜位、通道、区域和设施的位置，再在生产环境重新绑定机柜和设施 CI。
6. 如测试环境使用了参考底图，请在生产环境重新上传。确认无误后保存、校验并发布。

图纸文件会保留画布尺寸、外轮廓、墙、门、区域、机柜位、设施、文字、颜色、透明度、旋转和层级等绘图信息。它不会包含任何 CI 绑定、测试环境参考图或其他环境数据；原来已绑定的机柜位导入后统一显示为空位。不要手工修改 JSON 内容，格式版本不受支持、元素标识重复、编号重复、坐标越界或门挂接无效时，系统会拒绝导入并保留当前草稿。

## 校验和发布

发布前点击“校验”。常见阻断原因包括：

- 没有且只有一个有效的机房外轮廓。
- 轮廓自相交、坐标或元素几何不合法。
- 机柜位编号或元素标识重复。
- 已占用机柜位没有绑定机柜，或空位、预留位绑定了机柜。
- 机柜位绑定的 CI 不是机柜，或该机柜未与当前机房建立包含关系。
- 同一个 CI 在一张布局版本中被重复绑定。

校验通过后，填写版本说明并确认发布。已发布版本为只读快照，普通查看者只会看到该版本。之后再次编辑时，系统基于已发布版本形成新的草稿，不会影响正在查看的用户。

如果其他编辑者已经保存了更新，保存或发布会提示草稿冲突。请重新加载草稿，再将自己的修改与最新内容核对后继续，不要覆盖他人的布局。

## 版本、恢复和归档

在机房布局页打开“版本历史”可以查看每次已发布版本的编号、时间、说明和对象数量。

- **恢复**会把某个历史版本复制为新的草稿，不会直接改写当前已发布图。
- 当前草稿有未确认修改时，系统会阻止恢复，避免覆盖其他人的工作。
- 已发布布局不能删除，只能归档；归档保留历史版本和审计记录，也不会删除 CI、关系或参考图。
- 发布者可在布局列表切换到“已归档”，使用恢复按钮将归档布局重新设为活动布局。恢复前系统会检查该机房是否已有另一张活动布局；若已占用，会明确提示无法恢复，并保留归档布局不变。请先确认当前活动布局的处置方式，再重试恢复。
- 从未发布、且没有布局对象和参考图的空布局才允许删除。

## 建议的维护顺序

1. 在 CMDB 先维护楼宇、机房、机柜和设备 CI。
2. 使用正式关联把机房与机柜关联起来，再在空间布局中绑定机柜位。
3. 先配置机房外轮廓、通道和机柜列，再补充空调、UPS、配电柜等设施。
4. 保存草稿后进行校验，确认编号和绑定关系无误再发布。
5. 机柜内设备位置继续通过机柜 U 位图维护；设备上下游继续通过关系拓扑维护。
