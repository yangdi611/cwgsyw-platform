# IP 地址池管理

IPAM（IP 地址管理）用于规划和跟踪 IP 网段及其分配情况，避免 IP 冲突和地址浪费。

## 核心概念

- **IP 地址池（网段）** — 一段连续的 IP 地址范围，例如 `192.168.1.0/24`
- **IP 分配** — 把某个具体 IP 分配给某个用途/设备/配置项

## 查看地址池

进入 IPAM 页面：

- 列出所有 IP 地址池，显示网段、容量、已用/可用数量
- 点击进入查看该池内每个 IP 的分配明细

## 新建地址池

1. 点"新建地址池"
2. 填写网段（CIDR 格式，如 `10.0.0.0/24`）、名称、描述
3. 保存后系统按网段计算可用 IP 范围

创建前确认网段不会和现有地址池重叠，网关、DNS 和用途说明符合网络规划。地址池是规划对象，不会自动配置交换机、DHCP 或主机网络；实际网络变更仍应走变更文档。

## 分配与回收 IP

- **分配**：选择池内一个空闲 IP，登记用途、关联设备或配置项
- **回收**：释放已分配的 IP，使其重新可用

每个 IP 的状态一目了然：已分配 / 空闲 / 保留。

### 分配步骤

1. 打开地址池，先筛选空闲或保留状态的地址。
2. 选择目标 IP，填写用途和关联的 CI/设备。
3. 保存后状态变为已分配；在 CI 或设备侧核对引用是否正确。
4. 释放前确认主机、DNS、监控和相关变更已完成切换，再执行回收。

“保留”用于不可分配但暂不释放的地址，例如网关、VIP 或迁移窗口中的地址。不要将已分配地址直接标为空闲来绕过回收记录。

## 与 CMDB 的关系

IP 分配可关联到 [[CI 实例管理|CMDB 配置项]]，让"这个 IP 是哪台主机用的"有据可查。

## 权限

- `ip_pool:create` — 创建地址池
- `ip_pool:read` — 查看
- `ip_pool:update` — 分配/回收
- `ip_pool:delete` — 删除地址池

相关：[[CMDB 配置管理]]

## 排查

**无法分配**：检查该地址是否已分配或保留、地址池是否有效，以及是否有更新权限。

**发现冲突**：立即停止继续分配，核对关联 CI、实际网络和历史记录；必要时以变更文档记录纠正过程。
