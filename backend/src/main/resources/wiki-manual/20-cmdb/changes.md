# 变更历史与统计

CMDB 自动记录每个配置项的修改，方便追溯"谁在什么时候改了什么"。

## 变更记录

进入 **CMDB → 变更记录**：

- 全局变更时间线，按时间倒序展示所有 CI 的改动
- 多维过滤：按实体类型、模型、操作人、时间范围、操作类型（新建/修改/删除）
- 分页浏览

在单个实例的详情页，也能查看该实例自己的变更历史。

### 推荐查询方式

1. 先选时间范围，缩小到故障、发布或巡检发生的时间段。
2. 再按模型、实例、操作人或操作类型筛选。
3. 点击记录查看字段级“变更前 / 变更后”差异。
4. 如涉及生产变更，把变更单号、任务编号或告警时间与该记录交叉核对。

变更记录由系统在 CI 写操作后生成，不能在该页面手工补写或删除。若发现错误内容，应按权限修正当前 CI，并让新变更记录形成完整链路。

## 能看到什么

每条变更记录包含：

- 操作人
- 操作时间
- 操作类型（创建 / 更新 / 删除）
- 改动的具体字段（变更前 → 变更后）

## 变更统计

进入 **CMDB → 变更统计** 面板：

- **今日 / 本周 / 本月** 变更数量卡片
- **每日趋势** 图表
- **Top 10 活跃实例**（改动最频繁的 CI）

统计帮助你了解配置数据的变动节奏，识别异常频繁的改动。

## 用途

- **审计追溯** — 出问题时回查是谁、什么时候改的
- **变更复盘** — 配合[[变更文档]]核对实际改动
- **活跃度监控** — 通过统计发现异常

相关：[[CI 实例管理]]、[[关联与拓扑视图]]

## 阅读统计时的注意事项

变更统计按时间范围汇总创建、更新和删除动作，并展示活跃实例。它反映 CMDB 数据的编辑频率，不等同于生产故障数、任务完成数或变更文档通过数；这些口径应分别到告警中心、统一任务或变更文档查询。
