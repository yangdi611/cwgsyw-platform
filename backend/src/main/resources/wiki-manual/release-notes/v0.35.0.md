# v0.35.0 — 2026年7月14日

本次更新聚焦账号权限与用户组管理体验，让日常授权、组织调整和资源访问更清晰、更可靠。

## 新增

- **用户组归档与恢复**：管理员可先查看用户组的使用情况，再安全归档不再使用的用户组；需要时可恢复已归档的用户组。
- **用户组清理保护**：系统会明确提示仍在使用该用户组的成员、权限或业务内容，避免误操作影响日常工作。
- **权限与访问管理能力**：管理员可以更清楚地查看用户授权情况，并处理需要关注的授权配置。

## 优化

- **用户组浏览体验**：用户组列表区分当前使用和已归档内容，查找与管理更直观。
- **历史信息可读性**：已归档用户组在相关历史记录中仍保留名称，方便追溯过去的工作安排。
- **账号使用连续性**：系统更新后的登录状态处理更加平稳，减少不必要的重复登录。

## 修复

- **离开用户组后的访问控制**：修复成员离开用户组后，旧权限可能继续影响访问的问题。
- **资源访问范围判断**：修复部分共享内容、知识库和日常工作记录在组织调整后的访问判断不一致问题。
- **运维安排显示**：修复部分历史排班、任务和日报在用户组调整后显示不完整的问题。
