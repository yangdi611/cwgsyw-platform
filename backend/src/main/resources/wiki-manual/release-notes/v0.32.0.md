# v0.32.0 — 2026年7月6日

本次为安全修复版本，解决 Wiki 知识库权限控制缺陷和 CMDB 拓扑图展示不完整问题。

## 修复

- **Wiki 系统空间权限修正** — 修复"平台使用手册"和"Release Notes"空间的权限判断逻辑，现在所有用户（包括管理员）在这两个空间内都只能阅读和评论，无法编辑或删除页面。"Bug 反馈与建议"空间权限不变（所有用户可新建、编辑、发布反馈，仅管理员可删除）。

- **文档管理员角色权限范围调整** — 修复文档管理员（`doc_admin`）角色被误判为租户级管理员的问题，现在该角色的权限范围正确限定在所属运维组内，不再绕过空间和页面级 ACL 控制。**重要**：持有该角色的用户需重新登录才能生效新的权限范围（系统重启会自动清理所有会话，触发重新登录）。

- **CMDB 拓扑图双向关联展示** — 修复拓扑图只能单向展示关联关系的问题，现在从任意 CI 实例查看拓扑时都能完整看到所有相关联的节点。例如从资源池实例查看拓扑时，现在可以正确看到所有属于该资源池的主机节点。

## 数据库变更

- 迁移 V67：将 `sys_role` 表中 `doc_admin` 角色的 `scope` 从 `tenant` 调整为 `group`
- Wiki 系统空间的页面级 ACL 会在系统启动时自动重新校准，无需手动干预

## 兼容性

- 用户自建的 Wiki 空间权限行为不受影响
- CMDB 拓扑图的后端 API 响应格式不变，仅前端渲染逻辑优化
- 部署后所有用户会被强制重新登录（v0.30 引入的自动会话清理机制）
