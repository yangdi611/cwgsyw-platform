# v0.28.1 — 2026年7月3日

本次为修复性小版本，修正表格字段配置页的两个问题。

## 修复

- **编辑已有表格字段的列配置后保存报错（500）** — 修复了变更文档模板中，给已保存过的表格字段新增/修改列后点击「保存配置」报错的问题。首次保存表格字段正常，但再次修改列配置后保存必现失败，现已修复，保存不再报错。
- **列类型下拉框选中后显示英文代码** — 表格字段的「列配置」中，列类型下拉框选中后曾显示成内部代码（如 `text`）而不是中文名称（如"单行文本"），现已修正为正常显示中文名称。

## 兼容性

- 本次修复不涉及数据库结构变更，不影响已创建的表格字段数据。
