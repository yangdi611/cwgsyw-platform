# v0.31.0 — 2026年7月3日

本次为修复性小版本，修复登录状态异常时页面卡死不跳转登录页的问题。

## 修复

- **Token 失效/损坏时界面无感知卡死** — 此前若登录令牌被篡改、格式损坏，或自然过期后，后端会返回一个没有明确错误标识的403响应，导致前端无法识别这是登录状态问题，界面停留在原页面且所有操作均无响应，用户感受不到需要重新登录。现已修复：这类情况统一返回明确的登录失效提示，前端会自动清除本地登录状态并跳转至登录页面，用户可立即重新登录恢复使用。

## 兼容性

- 本次修复不涉及数据库结构变更，不影响已有业务数据。
- 正常登录状态下的使用体验不受影响。
