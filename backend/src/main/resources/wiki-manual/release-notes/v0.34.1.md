# v0.34.1 — 2026年7月11日

本次更新聚焦日常使用体验与稳定性，改善了权限访问、移动端浏览、共享文件和运维任务等常用场景。

## 优化

- **移动端工作台体验**：手机访问时导航、页头和操作区域会根据屏幕宽度自动调整，常用入口更容易查看和点击。
- **共享文件阅读体验**：文件预览区域会充分利用当前窗口空间，并在页面底部保留适当余量，长文档浏览更舒适。
- **CMDB 信息展示**：实例基本信息布局更加紧凑清晰，字段查看和编辑更加连贯。
- **页面交互稳定性**：优化搜索、配置和编辑页面的状态切换，减少重复打开、返回或重新加载时的信息错位。

## 修复

- **权限访问提示不准确**：无权访问流程、用户、用户组、角色或权限管理页面时，将直接返回工作台，不再显示空白或容易误解的空数据页面。
- **共享文件无法预览或下载**：修复部分文件一直停留在加载状态、无法下载或文件内容不完整的问题，并保留正确的文件名称。
- **临时运维任务无法继续处理**：修复未指定负责人时，创建人找不到或无法操作自己创建任务的问题；同时补充时间校验，减少无效任务。
- **手机页面横向溢出**：修复小屏幕下导航、页头和首页操作按钮超出可视范围的问题。
- **折叠菜单触控失效**：修复手机和平板上部分折叠菜单只能悬停、无法通过点击打开的问题。
- **模型属性维护异常**：修复新增或编辑模型属性时，字段类型、所属分组、选项和显示设置不准确的问题。
