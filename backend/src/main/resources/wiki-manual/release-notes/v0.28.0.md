# v0.28.0 — 2026年7月3日

本次为功能新增版本，变更文档模板新增「表格字段」类型，支持固定 Word 表格格式的动态加行填写与导出。

## 新增

- **变更文档字段新增「表格」类型** — 模板管理员可在变更文档模板配置页新增表格类型字段，配置列（文本/多行文本/数字/日期/日期时间/下拉选择/布尔值）、每列是否必填、行数上下限，以及是否允许填写人增行/删行。
- **Word 模板表格占位符** — 表格字段对应 Word 模板中的一行"数据行模板"，单元格占位符写作 `{{表格字段key.列key}}`。导出时按填写的行数复制该模板行并填充数据，保留模板行原有的列宽、边框、字体、底纹等格式。
- **解析书签自动识别表格** — 上传 .docx 后点击「解析书签」，若某一行的所有占位符都属于同一个表格字段 key，会自动识别为表格字段并推断出列配置。
- **填表页表格编辑器** — 变更文档新建/详情页中，表格字段渲染为可增行/删行的表格控件，填写人只能增删行、填写单元格内容，不能修改列结构。
- **必填校验时机** — 创建/编辑变更文档时只做结构性校验（不卡必填），提交（submit/submit-plan）时才校验表格必填列和整体最少行数，与其他字段的必填校验时机保持一致。

## 兼容性

- 已有的纯文本占位符 `{{fieldKey}}` 行为不变。
- 数据库新增 `change_doc_field.config`（JSONB）列，已有字段该列为空，不影响现有模板。
