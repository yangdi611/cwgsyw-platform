# v0.38.2 — 2026年7月26日

本次更新重新整理平台导航，并优化待处理信息与页面布局，使常用功能更容易查找，重要事项也更加醒目。

## 导航优化

- 调整侧边栏模块顺序，让任务、资源与文档、报表和流程等常用功能分区更加清晰。
- 优化 CMDB 菜单顺序，将空间布局更名为“机房视图”，并为尚未正式上线的功能增加明确提示。
- 将知识库归入“资源与文档中心”，方便集中访问设备密码库、IP 地址池、共享文档和知识内容。
- 移除重复的权限配置入口，相关设置统一从角色管理进入。

## 信息提醒

- 告警中心现在显示当前触发中的告警数量。
- 变更文档列表现在显示待审批和待补填方案的文档数量。
- 侧边栏数量提醒统一使用红色底白色字展示，重要待处理事项更加醒目。

## 体验改进

- 机房视图、新建变更文档和 AI 配置页面统一采用左对齐布局，与平台其他页面保持一致。
