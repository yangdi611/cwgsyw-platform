# v0.33.1 — 2026年7月7日

本次版本包含 CMDB 模型管理优化和概览页重构，简化导航层级，提升用户体验。

## 新增

- **自定义模型复制**：模型管理页支持复制自定义模型，可快速基于已有模型创建新模型，属性分组和属性定义会一并复制，实例数据不会复制。
- **自定义模型重命名**：自定义模型支持直接修改显示名称，模型标识保持不变，避免影响已有实例和关联。
- **CMDB 概览页实例浏览**：概览页新增实例浏览组件，默认展示最近更新的 CI，支持按模型、关键词和状态筛选，无需跳转即可快速查看实例详情。

## 优化

- **模型操作入口更完整**：自定义模型卡片现在集中提供打开设置、移动分类、重命名、复制和删除等常用操作。
- **模型名称展示更一致**：模型列表和模型详情页优先展示用户设置的显示名称，同时保留模型标识用于区分和排查。
- **CMDB 导航结构简化**：移除侧边栏"实例管理"独立入口，统一通过"概览"页进入，减少导航层级。访问 `/cmdb/instances` 会自动跳转到概览页。

## 修复

- **自定义模型删除入口缺失**：修复具备权限的用户在模型管理页看不到自定义模型删除按钮的问题。
- **模型删除后无法同名重建**：修复自定义模型删除后，再次创建相同模型标识会失败的问题。
- **模型属性删除后无法同名重建**：修复自定义属性删除后，再次创建相同字段标识会失败的问题。
- **模型删除清理不完整**：删除自定义模型时同步清理其属性分组和属性定义，避免后续重建、复制时出现残留冲突。

## 兼容性

- 本次改动不影响内置模型，内置模型仍不可删除、复制或重命名。
- 已有模型、实例、关联和告警数据不会被迁移或清空。
- 数据库迁移会自动调整 CMDB 元数据唯一性规则，使软删除后的历史记录不再阻塞新建同名模型或属性。
