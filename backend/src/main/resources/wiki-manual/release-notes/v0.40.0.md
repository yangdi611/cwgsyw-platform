# v0.40.0 — 2026年8月22日

本次更新继续完善上一轮体验升级后的细节，重点优化知识库、文件预览和系统管理相关页面，让日常查阅、编辑和配置更加顺手。

## 知识库与文件

- 知识库目录的常用操作收进“更多”菜单，文档标题不再被旁边的功能按钮挤占。
- 当前正在阅读的文档会以浅底色标出，方便在多层目录中快速定位。
- 收起目录的入口调整到正文区域，阅读空间更大，操作方向也更直观。
- 知识库编辑工具栏的图标更轻、更清晰，长时间编辑时视觉负担更小。
- 页面信息和权限设置集中到同一组操作中，减少重复标题和错位。
- 文件预览区域铺满可用空间，查看方案、附件等内容时不再显得过小。

## 系统管理与通知

- 系统配置、AI 配置、审计日志、备份与恢复、通知中心等页面的标题、筛选区和内容布局与平台其他模块保持一致。
- 配置页的开关、输入框和保存按钮更紧凑，不再占满整行过宽区域。
- AI 配置按供应商分页查看，切换时更清楚当前正在设置哪一家服务。
- 备份列表的下载、恢复和删除改为图标操作，鼠标移上去即可看到功能说明。
- 审计日志的筛选条件大小与其他列表页对齐，重置按钮位置更合理。

## 导航与开关

- 页面顶部的路径现在可以点击返回上级模块，例如从系统配置回到系统管理，从流程实例回到流程中心。
- 各类启用、关闭类滑动开关在切换时会平滑移动，状态变化更明确；全平台相同样式的开关都会一起生效。

## 使用提示

- 原有业务数据、账号权限和操作流程保持不变。
- 如果页面仍显示旧样式，请刷新浏览器后重新进入。
- 建议升级后重点查看知识库、文件预览、系统配置和通知中心，熟悉新的目录操作与配置入口。
