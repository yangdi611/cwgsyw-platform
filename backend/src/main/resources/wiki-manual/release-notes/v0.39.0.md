# v0.39.0 — 2026年8月19日

本次更新为平台带来一次覆盖主要工作区域的体验升级。页面风格、操作方式和信息层级更加统一，帮助用户更快找到所需功能、更清楚地了解当前状态，并在长时间使用时保持舒适、顺畅。

## 全新的平台体验

- 统一首页、我的工作、任务中心、运维日历、CMDB、变更文档、流程管理、知识库、文件中心、用户与权限等主要页面的视觉风格。
- 重新整理标题、筛选区、列表、状态提示和操作区域，减少页面之间的使用差异。
- 优化页面留白、文字层级和表格密度，让信息更清晰，同时在同一屏幕中展示更多有效内容。
- 完善加载中、暂无数据、操作失败和无权限等状态提示，遇到问题时更容易理解下一步该怎么做。

## 导航与个人入口

- 更新平台标志和侧边栏展示，展开与收起状态更加协调。
- 优化侧边栏底部的登录信息，头像、姓名和账号更易辨认；没有头像时会使用醒目的姓氏头像代替。
- 个人资料、修改密码和退出登录集中在更简洁的个人菜单中，点击页面其他区域即可收起。
- 深浅色切换和通知中心入口移到页面右上角，可随时切换显示模式或直接查看通知；有新通知时会显示红点提醒。
- 优化全局搜索结果的分组与展示方式，查找页面和功能时更加直观。

## 日常工作与任务处理

- 优化“我的工作”的筛选、分类和列表布局，在常用办公屏幕下浏览更加稳定，避免出现多余滚动条。
- 统一任务列表、任务详情、计划、模板、统计、指标和自动化规则的操作方式，减少来回切换时的学习成本。
- 运维日历的日期切换、视图选择、任务筛选和详情查看更加紧凑清晰。
- 待处理、审批、完成状态和优先级信息更加醒目，便于快速判断下一步工作。

## 资源、文档与流程管理

- 优化 CMDB、设备、IP 地址、文件和知识库的列表、搜索、详情与操作入口，资源信息更容易查找和浏览。
- 首页资源概览更加直观，可快速了解不同资源类型的占比情况。
- 改进变更文档的创建、查看和处理流程，重要步骤与操作反馈更加明确。
- 优化流程设计、流程实例、模板和绑定管理页面，运行状态与可执行操作更容易识别。
- 统一用户、用户组、角色和权限页面的选择与确认方式，降低误操作的可能性。

## 交互与可读性改进

- 下拉选择、弹出窗口、侧边抽屉和确认提示采用一致的打开、关闭与反馈方式。
- 优化常用图标和状态颜色，使编辑、删除、提醒、查看和切换等操作更容易辨认。
- 改善较窄窗口和常用办公分辨率下的排列与滚动体验，减少内容被遮挡或页面横向滚动的情况。
- 深色模式下的文字、边框、背景和状态提示更加协调，长时间使用更舒适。

## 使用提示

- 原有业务数据、账号权限和操作流程保持不变，升级后可以继续按原有方式开展工作。
- 如果页面仍显示旧样式，请刷新浏览器后重新进入。
- 建议在升级后重点查看“我的工作”、任务中心、运维日历、CMDB 和流程管理等常用区域，熟悉新的页面布局与快捷入口。
