# v0.31.1 — 2026年7月4日

本次为功能性小版本，Wiki 阅读模式下的图片新增点击放大功能。

## 新增

- **Wiki 图片点击放大** — 浏览 Wiki 页面时，点击正文中的图片可打开全屏遮罩查看大图：
  - 半透明黑色背景遮罩，右上角有明显的关闭按钮
  - 点击遮罩空白区域（非图片本身）也可关闭
  - 支持鼠标滚轮缩放（0.5～6 倍）
  - 支持按住鼠标左键拖动查看图片局部细节
  - 支持按 `Esc` 键快速关闭
  - 遮罩打开期间背后页面不会跟随滚动

## 兼容性

- 仅影响 Wiki 阅读页的图片展示，编辑器内的图片预览行为不变。
- 本次改动不涉及数据库结构变更，不影响已有业务数据。
