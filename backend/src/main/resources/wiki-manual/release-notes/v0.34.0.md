# v0.34.0 — 2026年7月9日

本次版本完成了代码质量全面改善，重构了 CMDB 模型管理页的组件架构，建立了前后端类型契约体系，同时修复了 BPMN 编辑器键盘绑定兼容性问题。

## 代码质量

- **前端类型体系建立**：新增 `api.ts`、`cmdb.ts`、`workflow.ts` 共享类型定义和安全错误处理工具 `api-error.ts`，覆盖 API 响应包装、分页结构、CMDB 模型/实例/关联、工作流定义等稳定契约，减少 `any` 类型使用。
- **前端 lint 改善**：修复了 BPMN 编辑器声明顺序错误（`renderFlowFields` 在 `renderSelectionFields` 之前声明）、React hooks 依赖缺失、`setState-in-effect` 性能风险等高信号问题，全局 lint 问题从 191 减少至 156。
- **后端 DTO 补全**：为水印配置（`WatermarkConfigRequest`）、共享文件夹创建（`CreateFolderRequest`）、工作流版本删除（`DeleteVersionRequest`）补充了类型化请求 DTO，替换原有的 `Map<String, Object>` 参数接收，支持 camelCase/snake_case 双别名向后兼容。
- **前端 typecheck 脚本**：`package.json` 新增 `typecheck` 脚本，`tsc --noEmit` 可独立运行，便于 CI 接入。

## 重构

- **CMDB 模型管理页拆分**：将原 1697 行的 `cmdb/admin/page.tsx` 拆分为 8 个独立模块（`ModelCard`、`ModelCatalogTab`、`AssociationsTab`、`AssociationDefsSection`、`AttributeGroupsTab`、共享类型/工具文件），主页面缩减至 63 行，各 tab 独立可维护。
- **工作流管理页类型化**：`workflow/admin/page.tsx` 全面替换本地 `ProcessDef` 为共享 `ProcessDefinition` 类型，5 处 `catch (err: any)` 改为 `catch (err: unknown)` + 统一错误消息提取，错误 toast 行为等价。

## 修复

- **BPMN 编辑器键盘绑定**：移除 `keyboard: { bindTo: document }` 配置，兼容新版 bpmn-js/diagram-js 的隐式键盘绑定机制，消除控制台 `unsupported configuration <keyboard.bindTo>` 错误。

## 兼容性

- 所有 API 端点、请求/响应结构、数据库 schema 保持不变
- 后端新增 DTO 通过 `@JsonAlias` 同时兼容 camelCase 和 snake_case 请求体
- CMDB 模型管理三个 tab 的功能、路由、权限控制、query key 完全保持
- 工作流、共享文件、系统配置的前端行为保持不变
