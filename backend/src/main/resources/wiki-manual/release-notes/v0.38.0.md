# v0.38.0 — 2026年7月26日

本次更新新增机房空间布局功能，通过统一的二维视图呈现机房结构、机柜位置和设施分布，并与 CMDB 中的机柜、设备、状态和告警信息联动，帮助运维人员更直观地了解设备所在位置和机房整体情况。

## 新增

- **机房二维布局**：可为不同机房绘制独立布局，在同一画布中展示外轮廓、墙体、门、通道、区域、机柜位、设施和文字说明。
- **机柜与设施关联**：机柜位和设施可以绑定现有 CI，已被其他位置使用的机柜不会重复出现在候选列表中。
- **运行状态展示**：已绑定机柜可按正常、告警、容量和数据质量等状态显示不同颜色，便于快速发现需要关注的位置。
- **机柜视图联动**：点击布局中的机柜，可以直接查看机柜内部设备、CI 详情和关系拓扑。
- **空间搜索定位**：可根据机柜或设备信息定位到所属机房和机柜位置。
- **版本与归档**：布局支持草稿、校验、发布、历史版本、恢复和归档；归档布局也可以在符合条件时恢复使用。
- **图纸导入导出**：可在测试环境完成绘制后导出图纸，再导入生产环境继续使用；图纸不包含 CI 绑定和参考底图。

## 编辑体验

- 支持上传机房平面图作为绘制参考，并可调整显示范围、透明度和锁定状态。
- 支持自由调整机房外轮廓、区域、通道、机柜和设施的大小、位置、颜色、透明度和层级。
- 支持批量生成机柜位，可选择横向或纵向排列、正序或倒序编号，并预先设置机柜尺寸和间距。
- 支持多选、批量调整尺寸与间距、批量删除、复制粘贴以及常用键盘快捷键。
- 支持边缘对齐、中心对齐、等距分布、智能参考线和远距离对齐。
- 支持机柜之间、墙体端点和门与墙体之间的吸附，帮助快速绘制整齐规范的布局。
- 区域可以自定义颜色和透明度，并在布局底层显示，避免遮挡机柜和其他设备。

## 使用提示

- 建议先在 CMDB 中维护机房、机柜和设备关系，再进入空间布局绑定机柜 CI。
- 发布前请执行校验，确认机房外轮廓、机柜编号、门的位置和 CI 绑定均符合要求。
- 从其他环境导入图纸后，需要在当前环境重新绑定机柜和设施 CI；参考底图也需要重新上传。
- 已发布布局不会被后续草稿直接覆盖，确认新草稿无误后再发布即可切换查看版本。
