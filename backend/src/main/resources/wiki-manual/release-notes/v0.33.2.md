# v0.33.2 — 2026年7月7日

本次版本重构了 CMDB 首页模型组展示方式，从平铺卡片改为 tab 切换，提升浏览效率和视觉一致性。

## 优化

- **CMDB 首页模型组展示重构**：将原有的平铺模型组卡片改为顶部 tab 切换模式，减少页面纵向高度占用，提升模型组间切换效率。
- **单色模型组标识**：每个模型组使用稳定的单色胶囊图标，组内模型使用同色系深浅变化，建立清晰的视觉归属关系。
- **模型图标中文首字显示**：模型卡片图标显示模型显示名的首个汉字（如"服务器"显示"服"），提升中文模型的识别度。
- **激活态流动动画**：当前选中的模型组 tab 底部显示流动渐变下划线，支持 `prefers-reduced-motion` 降级。
- **内容区信息优化**：显示当前模型组描述、统计数据（模型数/实例数/字段数）和模型卡片网格，不重复展示模型组名称。

## 移除

- **模型组平铺卡片**：移除了旧的平铺展示方式和弹层，统一使用 tab 内联展示。

## 兼容性

- 模型点击跳转路由保持不变：`/cmdb/instances/by-model/{modelId}`
- 实例浏览区（InstanceBrowserSection）保持在模型组展示区下方，功能不受影响
- 所有 CMDB 数据接口和权限控制保持不变
