# v0.36.0 — 2026年7月22日

本次更新围绕日常工作的完整性、清晰度与稳定性展开，改善了资产管理、知识协作、变更审批、运维安排和管理设置等常用场景。

## 新增

- **跨组负责人选择**：创建运维任务时，可以从当前组织内的可用成员中选择负责人，跨组协作更顺畅。
- **变更审批信息归档**：变更材料可保留审批结果、审批人、时间和意见，回顾处理过程更方便。
- **通知目标引导**：从通知进入相关内容时，会先确认内容是否仍可查看；内容已移除时会给出清晰提示。
- **流程绑定管理**：流程绑定支持新增、编辑、启用、停用和删除，日常维护更完整。

## 优化

- **资产信息浏览**：资产详情、关联设备、变更记录、影响范围和历史关系之间的跳转更连贯。
- **知识库与共享文件**：页面、附件、文件夹和文件的创建、移动、重命名、预览、下载与导出体验更加一致。
- **变更文档处理**：模板填写、关联资产、提交审批、待办跳转、结果查看和材料导出更加顺畅。
- **日报与运维协作**：日报提交审批、任务安排、排班、节假日、周期规则、统计和素材归集的操作提示更清楚。
- **管理页面体验**：账号、用户组、角色、通知、备份和各项设置的入口与反馈更加统一。
- **常用操作稳定性**：搜索、分页、日期选择、弹窗关闭、重复点击和页面返回等操作更加可靠。

## 修复

- **组织调整后的访问异常**：修复成员、用户组或角色发生变化后，部分内容仍可看到或无法及时访问的问题。
- **资产关系显示不完整**：修复部分关联设备、变更文档、日报、拓扑和影响信息缺失或跳转不准确的问题。
- **审批过程不连贯**：修复部分日报、知识页面和变更文档提交后没有正确进入待办或无法继续处理的问题。
- **文件与导出内容不一致**：修复部分文件移动、预览、下载及文档导出后名称、内容或顺序不准确的问题。
- **输入与重复操作提示不足**：修复空白内容、过长内容、无效日期、重复名称和连续点击可能造成结果不明确的问题。
- **通知与历史记录缺失**：修复部分状态变化、审批结果和管理操作没有留下清晰通知或记录的问题。
