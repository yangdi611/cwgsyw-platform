# v0.36.0 — 2026年7月24日

本次更新带来统一任务中心。日报、巡检、周报等日常工作可用同一种方式创建、安排、执行和查看，让任务协作更清楚。

## 全新统一任务中心

- **任务统一管理**：日报、周报、巡检、临时事项等均在任务中心创建和处理，不再需要在多个入口之间切换。
- **可定制任务内容**：创建人可按实际工作要求配置填写内容、附件提交、说明文字和完成要求。
- **周期与一次性安排**：支持按日、周、月、季度等周期安排任务，也支持随时创建一次性任务。
- **任务模板与计划**：常用工作可沉淀为模板和计划，后续重复工作可直接复用。

## 我的工作与审批

- **集中处理待办**：待执行、待审批、我发起的、抄送我的和已完成任务集中展示，工作状态一目了然。
- **清晰的审批反馈**：审批人退回任务时可填写原因，执行人会在任务中看到具体反馈，修改后可重新提交。
- **按需设置审批**：创建任务时可决定是否需要审批，并设置相应的处理人。
- **提醒与进度跟进**：任务会在需要关注的时间提醒相关人员，逾期和待处理状态更容易发现。

## 运维日历

- **一个页面查看多种视图**：运维日历支持月视图、周视图和列表视图切换，便于从不同时间范围安排工作。
- **快速进入任务**：可从日历直接查看和处理当天或指定时间的任务。
- **统一查看工作安排**：任务、排班和节假日可在同一日历中查看，减少遗漏。

## 统计与分析

- **自定义统计内容**：任务中的数字、选项、文字和附件可按各自特点汇总查看；不同类型的日报、周报或巡检可使用各自的统计口径。
- **多维度查看结果**：可按时间、人员、用户组、关联 CI 和任务模板了解完成情况及填写结果。
- **指标与图表展示**：对需要持续关注的数值，可设置合计、平均值、计数等统计方式，并以图表辅助查看变化。

## 使用提醒

- 原有日报、巡检和临时运维安排，请在任务中心中继续处理或创建。
- 创建周期性工作前，建议先配置好任务模板、执行人、提交要求、提醒时间和审批规则。
- 不同报表的统计口径可以分别设置，无需让所有报表使用同一套字段。
