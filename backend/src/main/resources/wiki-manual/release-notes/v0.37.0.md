# v0.37.0 — 2026年7月25日

本次更新进一步完善任务中心，重点提升自定义表格、任务统计、模板管理和日常操作体验，让周报、巡检、清单等复杂任务更容易配置和使用。

## 新增

- **自定义表格**：任务模板可以配置表格列、表头和填写类型，适合周报明细、巡检记录、工作清单等场景。
- **灵活增减行**：执行人填写任务时，可以根据实际内容新增、复制或删除表格行，不再受固定行数限制。
- **丰富的列类型**：表格支持自增序号、文字、数字、日期、选项、附件和图片等内容。
- **表格数字汇总**：数字列可以按需要展示合计、平均值、最小值或最大值。
- **多字段统计**：运行任务统计时可以同时选择多个字段，集中查看同一任务中的多项数据。

## 优化

- **统计结果更易读**：执行人和执行组优先显示名称，统计字段、时间和结果列的名称与顺序更加清晰。
- **中文显示一致**：任务计划、运维日历、我的工作、指标管理和自动化规则中的选项统一显示中文；选择后保持与下拉列表一致。
- **任务提交体验**：完善表格任务的草稿保存、增删行、附件填写和正式提交体验。
- **模板管理更明确**：未被任务使用的模板可以直接删除；已被使用的模板会受到保护，避免影响现有工作。
- **运维日历显示**：当前日期更加醒目，任务筛选中的模板、负责人、用户组和状态名称更加直观。
- **审批查看体验**：审批人可以查看表格填写内容和相关附件，并对需要修改的内容给出明确意见。

## 修复

- 修复部分周期任务激活后未正确出现在运维日历中的问题。
- 修复部分任务填写完成后无法校验或提交的问题。
- 修复自定义表格新增、删除或复制行时提示行标识无效或重复的问题。
- 修复任务统计中执行人或执行组显示为编号的问题。
- 修复部分统计查询失败、结果表头不统一或字段显示不完整的问题。
- 修复下拉选项选择后显示英文值或编号的问题。

## 使用提示

- 创建表格任务时，模板设计人负责确定列数、表头、列类型和行数范围；执行人只需按实际工作内容增减行。
- 需要汇总的数字列可在模板中设置汇总方式，提交后的数据可继续用于任务统计。
- 删除模板前请确认其未被任务使用；已经投入使用的模板会保留，确保历史任务可以正常查看。
