# Wiki 知识库使用说明

Wiki 知识库用于团队知识沉淀，支持多空间、树形页面、Markdown 编辑、双向链接、知识图谱和版本历史。你正在阅读的这份手册就在 Wiki 里。

## 空间与页面

- **空间（Space）** — 顶级隔离单元，类似一个独立的知识库（如"运维手册"、"项目文档"）
- **页面（Page）** — 空间内的文档，可以有父子层级，形成目录树

进入 **Wiki** 看到所有空间卡片，点击"进入"打开某个空间。

空间的可见性和可写性由所有者、角色、组和 ACL 决定。看不到空间或页面时，不要用标题猜测链接；请由空间管理员授予最小必要的读取权限。

## 创建内容

> 注意：本「平台使用手册」空间是系统维护的只读空间，普通用户不能编辑。下面说明针对你自己创建的空间。

- **新建空间**：在 Wiki 首页点"新建空间"
- **新建页面**：在空间内的左侧树点 + 号，可建顶级页或子页
- **编辑页面**：进入页面点"编辑"，用 Markdown 编写
- **移动页面**：在树中拖拽调整层级和顺序

### 推荐编写流程

1. 先选择或创建正确的空间，避免把项目文档写进平台使用手册等系统空间。
2. 新建页面时填写清晰标题；同一空间内避免创建近似标题导致链接歧义。
3. 在编辑器中编写正文，保存草稿后预览排版和链接。
4. 需要对外可见时按空间规则提交审批或发布。
5. 重要更新在版本历史中留下可识别的版本说明，便于回溯。

## Markdown 编辑器

页面正文用 Markdown 编写，支持标题、列表、表格、代码块、图片等。编辑时自动保存草稿。

自动保存降低浏览器异常关闭的风险，但不等于已发布。离开页面前确认保存状态；多人同时编辑同一页时，以页面提示的最新版本为准，避免用旧草稿覆盖他人内容。

## 双向链接

用 `[[页面标题]]` 语法引用其他页面：

- 输入 `[[` 会触发自动补全
- 链接会渲染成可点击的跳转
- 被链接的页面能看到"哪些页面引用了我"（反向链接面板）

例如本手册中的 [[CMDB 配置管理]]、[[设备密码库]] 都是双向链接。

## 知识图谱

每个空间可查看知识图谱：以图形展示页面之间的链接关系，直观看到知识结构和孤立页面。

## 版本历史

每次保存都会留下版本快照：

- 在页面查看"版本历史"
- 可对比、回滚到任意历史版本

回滚会产生新的当前版本，不会抹去已存在的历史。回滚前先比较差异并确认不会恢复过期的联系方式、操作步骤或敏感信息。

## 发布与审批

页面有状态：草稿 → 审批中 → 已发布。

- 普通空间的页面可提交审批，审批通过后发布
- 发布后才会出现在知识图谱中

系统维护的“平台使用手册”和 Release Notes 空间为只读种子内容：普通用户不能直接改写。发现说明错误时，应在 Bug 反馈与建议空间提交问题，并提供页面标题、操作步骤和截图/期望结果。

## 搜索

Wiki 提供全文搜索，跨空间或限定空间查找页面。

## 导出

支持把单个页面或整个空间导出，便于离线保存或分享。

## 权限

| 权限 | 能做什么 |
|------|---------|
| `wiki:read` | 浏览 |
| `wiki:create` | 创建空间/页面 |
| `wiki:update` | 编辑 |
| `wiki:delete` | 删除 |
| `wiki:publish` | 发布 |
| `wiki:manage_acl` | 配置页面访问权限 |

还可对单个页面设置 ACL（继承式），用法类似[[共享文件库]]的文件夹权限。

## 搜索与排查

搜索时先使用准确标题或关键词，再限定空间缩小结果。链接显示“待创建”说明当前空间没有可访问的对应页面；应创建页面、修正标题或请求授权，而不是把链接文本当作已存在内容。
