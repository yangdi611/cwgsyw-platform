# 共享文件库

共享文件库是团队的文件中心，支持文件夹树、上传下载、在线预览、按文件夹设置访问权限，以及变更文档自动归档。

## 浏览文件

进入 **文件管理** 页：

- 左侧是文件夹树，点击文件夹查看其中的文件
- 右侧表格列出文件，支持关键词搜索、分页
- 底部可展开操作日志面板

先选文件夹再搜索，可将结果限制在当前目录或按系统页面提供的范围检索。文件夹树的展开、收起和选中只影响当前用户的浏览状态，不会移动或修改文件。

## 文件夹管理

- **新建文件夹**：在当前位置创建子文件夹
- **删除文件夹**：仅当文件夹为空（无文件、无子文件夹）时可删

新建根目录时，如页面要求选择所属组，应选择实际负责该资料的团队；后续子文件夹默认继承父目录的归属和权限。移动文件夹、重命名和删除前先检查其中是否有归档文件或其他团队正在引用的资料。

## 上传文件

1. 进入目标文件夹
2. 点"上传"，选择文件
3. 上传后文件归入当前文件夹
4. Word 文档会自动生成预览

上传进度完成并出现成功提示后，文件才已进入当前目录。上传错误时先检查文件大小、网络、目标文件夹权限和存储服务，不要在不确定是否成功时反复上传同名文件。

## 下载与预览

- **下载**：生成临时下载链接（有效期 5 分钟）
- **预览**：在线预览（有效期 30 分钟）
  - PDF 直接在浏览器查看
  - Word（docx）在线渲染
  - Excel 表格在线展示

临时下载和预览链接有有效期，到期后重新从文件列表操作即可。下载或预览失败通常是权限不足、文件已删除、链接过期或文件格式不支持；不要将临时链接转发给无权访问的人员。

## 文件夹访问权限（ACL）

可对文件夹设置细粒度的访问权限，控制谁能读/写/改/删：

- **继承（默认）**：跟随父文件夹的权限
- **自定义**：本文件夹用独立权限，可比父级更严或更松

权限主体可以是**角色**、**用户组**或**具体人员**，权限动词包括：

| 动词 | 含义 |
|------|------|
| read | 浏览查看 |
| write | 上传、建子文件夹 |
| update | 重命名 |
| delete | 删文件、删空文件夹 |

设置 ACL 需要 `shared_file:manage_acl` 权限。设置了自定义权限的文件夹会显示锁标记。管理员始终可访问。

### 配置 ACL 的步骤

1. 在文件夹树或文件操作中打开“权限设置”。
2. 先查看是否继承父目录；确需独立控制时再切换为自定义。
3. 添加角色、用户组或用户，分别勾选 read、write、update、delete。
4. 保存后使用目标角色的最小可见范围核对，不要给所有人授予 delete。

文件也可以设置独立访问控制。独立 ACL 适合敏感归档或跨组协作资料，不能用来绕过上级目录的安全管理规范。

## 变更文档归档

[[变更文档]]审批通过后，会自动归档到本文件库（「变更文档 / 年 / 月」目录），无需手动上传。

## 权限

| 权限 | 能做什么 |
|------|---------|
| `shared_file:read` | 浏览、下载 |
| `shared_file:upload` | 上传 |
| `shared_file:delete` | 删除 |
| `shared_file:manage_acl` | 配置文件夹权限 |

相关：[[变更文档]]、[[用户与权限管理]]

## 常见问题

**看不到文件夹或文件**：先确认所在组和目录 ACL；管理员可检查继承和自定义权限是否冲突。

**无法删除目录**：目录必须没有文件和子目录。先按保留要求移动或删除内容，再删除空目录。

**归档文档找不到**：从变更文档确认审批与归档完成，再到“变更文档 / 年 / 月”目录检查；仍无权限时联系文件管理员。
